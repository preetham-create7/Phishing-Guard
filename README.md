# Phishing Guard 🛡️

## About the Project
Phishing Guard is a beginner-friendly cybersecurity project designed to identify potentially suspicious and phishing URLs.

## Features
- Accepts website URLs from users.
- Scans submitted URLs.
- Identifies potentially suspicious URLs.
- Displays scan results through a simple web interface.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## Project Structure
- `app.py` – Python Flask application.
- `templates/` – HTML files.
- `static/` – CSS and JavaScript files.

## How to Run

1. Clone this repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Start the application:

   `python app.py`

4. Open the local URL displayed in your terminal.

## Purpose
This project was developed to learn practical cybersecurity concepts and understand how phishing URL detection tools work.

## Disclaimer
This project is for educational purposes. Detection results are not guaranteed to identify every phishing website.
